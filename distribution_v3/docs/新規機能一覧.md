## 使い分け

| 見たい内容 | 推奨機能 |
|-----------|----------|
| 月次で見た全体計画 | `CreateRoadmapOverviewSheet` |
| 完了済みタスクを一覧内で見分けたい | メインシートの完了グレー表示 |
| 大量入力中に Ctrl+Z を使いたい | `ToggleBulkEditMode` |
| WBS の入力部分だけ安全に退避したい | `CreateWbsBackupSheet` |
| Lite版でバックアップとの差分を見たい | `CreateWbsBackupDiffSheet` |

## 補足

- 俯瞰系として現行で残しているのは `WBSサマリ` のみです。
- 旧 `WBS全体サマリ` `WBSダッシュボード` `WBSフィルタビュー` `完了表現ガイド` はアーカイブ扱いです。
- Excel へ取り込むファイルは `_SJIS.bas` です。
- `SheetModule_SJIS.bas` は標準モジュールではなく、`InazumaGantt_v3` シートモジュールへ貼り付けます。
- Lite版を使う場合は `SheetModule_Lite_SJIS.bas` を `InazumaGantt_Lite` シートモジュールへ貼り付けます。
