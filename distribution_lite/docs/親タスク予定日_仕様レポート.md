# 親タスク予定日 仕様レポート

作成日: 2026-05-11 00:40 JST
作成者: Codex (GPT-5)

## 目的

親タスクの `L:開始予定` と `M:完了予定` を、旧版に近い「親行にも日付が入る」使い勝手へ戻しつつ、利用者が親行の日付を手で調整したい場合も壊さない仕様にした。

## 推奨仕様

1. 親行の `L:M` が空欄の場合は、`ガント更新` 時に配下タスクから自動計算する。
2. 開始予定は配下タスクの最小開始予定日、完了予定は配下タスクの最大完了予定日を使う。
3. 親行の開始予定または完了予定を手入力で変更した場合、そのセルは手入力値として保持する。
4. 開始予定と完了予定は独立して判定する。開始予定だけ手入力、完了予定だけ自動追従という使い方ができる。
5. 手入力扱いになった親日付を空欄に戻すと、次回の `ガント更新` で自動計算へ戻る。
6. 子タスクの日付が Excel シリアル値として入っていても、親予定日の自動計算に利用する。

## 判定の仕組み

親予定日の直前の自動計算値を、非表示シート `_InazumaParentDateState` に保持する。

- 現在の親セルが空欄の場合: 自動計算値を書き込む。
- 現在の親セルが直前の自動計算値と同じ場合: 自動入力値とみなし、最新の子タスク日付へ追従する。
- 現在の親セルが直前の自動計算値と異なる場合: 利用者の手入力値とみなし、上書きしない。

## 検証

`dev/tools/Invoke-InazumaAcceptanceTests.ps1` に `TC-20 親予定日の自動入力と手入力保持` を追加した。

確認内容:

- LV2 / LV1 親行の開始予定と完了予定が空欄から自動補完される。
- 子タスクの日付変更に、親行の自動日付が追従する。
- 親行の開始予定を手入力した場合、子タスク日付が変わっても保持される。
- 手入力していない完了予定は、同じ親行でも子タスク日付へ追従し続ける。
- 手入力した開始予定を空欄に戻すと、自動計算へ復帰する。

最終確認では、配布ブックと配布 bundle 復元ブックを含めて `OK=78 / NG=0` を確認した。

## 関連修正

親予定日が入ることで、Lite版のイナズマ線がガント左端ちょうどに接続されるケースが増えた。Excel Freeform の線幅ぶんだけ図形の左端がガント領域外と判定されるため、イナズマ線の接続点をガント領域内へクランプする修正も行った。
