# 高速入力・状況・進捗率 受入テストケース集

- 作成日: 2026-05-06 20:37 JST
- 作成者: Codex (GPT-5)
- 更新日: 2026-05-10

## 目的

今回修正した `一括編集 ON/OFF`、`H:状況`、`I:進捗率` と、その周辺のボタン・図形・ガント表示について、最終製品に近い配布ブックで確認するための受入テストケース集です。

既存の build smoke test と重複する単純なマクロ起動確認、基本的な workbook 生成確認、単一行の `70 -> 進行中` 確認は対象外にします。このテストケース集では、実際の利用者操作に近い連続操作、ボタン押下、貼り付け、保存・再オープン、図形のずれを重点確認します。

## 対象ブック

原則として、配布フォルダ内の最新 `.xlsm` をコピーして実施します。

| 版 | 対象 |
|---|---|
| 標準版 | `distribution_v3/excel/InazumaGantt_v3_*.xlsm` |
| Lite版 | `distribution_lite/excel/InazumaGantt_Lite_*.xlsm` |

## 共通前提

1. テスト前に対象 `.xlsm` を任意の作業用フォルダへコピーする。
2. Excel で開き、マクロを有効化する。
3. 表示倍率はまず `100%`、必要に応じて `80%` と `125%` でも確認する。
4. テスト後に保存確認が出た場合は、作業コピーだけを保存または破棄する。
5. 各テストは標準版と Lite 版の両方で実施する。ただし実績列 `N:O` に関する確認は標準版のみ対象とする。

## 判定基準

| 判定 | 基準 |
|---|---|
| OK | 期待結果を満たし、エラー・表示崩れ・ボタン重複・操作不能がない |
| NG | 期待結果と異なる、VBA エラーが出る、ボタンや図形がずれる、ON/OFF 状態が戻らない |
| 保留 | 環境依存または仕様判断が必要で、再現情報を残して判断待ち |

## テストケース

### TC-01 初期表示とボタン配置

| 項目 | 内容 |
|---|---|
| 目的 | 配布ブックを開いた直後に、操作ボタン・ステータス表示・ガント領域がずれていないことを確認する |
| 手順 | 1. 対象ブックを開く。<br>2. `InazumaGantt_v3` または `InazumaGantt_Lite` シートを表示する。<br>3. 画面上部のボタン群、`A3:J3` の高速入力表示、日付ヘッダー、ガント領域を確認する。<br>4. 表示倍率を `80%`、`100%`、`125%` に切り替えて確認する。 |
| 期待結果 | ボタンが重ならない。ボタン文字が切れない。`高速入力 OFF` の表示が見える。日付ヘッダーとガント領域が列に沿っている。H列・I列を選択しても入力メッセージが出ない。 |
| 補足 | 図形がセルから大きく外れている、ボタンが複数重なっている、文字が読めない場合は NG。 |

### TC-02 高速入力 ON ボタン押下

| 項目 | 内容 |
|---|---|
| 目的 | `一括編集 ON/OFF` ボタンを押したときに ON 状態へ正しく切り替わることを確認する |
| 手順 | 1. `一括編集 ON/OFF` ボタンを 1 回押す。<br>2. ボタン表示と `A3:J3` のメッセージを確認する。<br>3. C-F 列の空き行にタスクを 1 件入力する。 |
| 期待結果 | ボタンまたは表示が `高速入力 ON` になる。`A3:J3` に ON 中である旨が表示される。C-F列の空き行にタスクを入力すると A列の LV が表示される。ガントや親集計が即時反映されなくても仕様通り。VBA エラーは出ない。 |
| 補足 | ON にした直後に OFF へ戻る、ボタン表示と `A3:J3` 表示が食い違う場合は NG。 |

### TC-03 高速入力 ON 中の Ctrl+Z

| 項目 | 内容 |
|---|---|
| 目的 | 高速入力 ON 中に Excel 標準の Undo を使いやすい状態が維持されることを確認する |
| 手順 | 1. 高速入力を ON にする。<br>2. C-F 列の空き行へ 3 行分のタスクを貼り付ける。<br>3. `Ctrl+Z` を 1 回押す。 |
| 期待結果 | 直前の貼り付けが取り消される。VBA エラーは出ない。高速入力 ON 表示が残る。 |
| 補足 | Undo が効かない場合は、直前に別マクロ操作をしていないかを記録する。 |

### TC-04 高速入力 OFF 復帰時の一括再整合

| 項目 | 内容 |
|---|---|
| 目的 | ON 中にまとめて入力した内容が、OFF 復帰時に正しく再整合されることを確認する |
| 手順 | 1. 高速入力を ON にする。<br>2. C-F 列に親子構造を含むタスクを 5 行以上貼り付ける。<br>3. H/I/K/L/M 列にも値を入れる。<br>4. `一括編集 ON/OFF` ボタンを押して OFF に戻す。 |
| 期待結果 | `高速入力 OFF` 表示になる。LV、No.、状況、進捗率、親集計、ガント表示が整合する。ボタンが重複しない。ガント図形が行や日付列からずれない。 |
| 補足 | OFF 復帰後に表示が合わない場合は、`ガント更新` を押す前の状態をスクリーンショットで残す。 |

### TC-05 高速入力ボタン連打

| 項目 | 内容 |
|---|---|
| 目的 | ON/OFF ボタンを連続操作しても状態が壊れないことを確認する |
| 手順 | 1. `一括編集 ON/OFF` ボタンを 10 回連続で押す。<br>2. 最後の表示状態を確認する。<br>3. C-F 列に 1 件タスクを入力する。<br>4. 必要ならもう一度ボタンを押して OFF に戻す。 |
| 期待結果 | 奇数回なら ON、偶数回なら OFF と表示が一致する。ボタンが増殖しない。タスク入力後に Excel が操作不能にならない。 |
| 補足 | 状態が不明になった場合は `ガント更新` 実行後の表示も記録する。 |

### TC-06 状況列の直接変更

| 項目 | 内容 |
|---|---|
| 目的 | 状況を直接選んだときに、選択した状況が保持されることを確認する |
| 手順 | 1. 通常モード OFF 状態で、タスク行を 4 行用意する。<br>2. H列を順に `未着手`、`進行中`、`完了`、`保留` へ変更する。<br>3. I列の値を確認する。 |
| 期待結果 | `未着手 -> 0%`、`進行中 -> 50%`、`完了 -> 100%`、`保留 -> 既存進捗率保持、未入力なら 0%` になる。H列が勝手に別の状況へ戻らない。 |
| 補足 | 既存進捗率がある `保留` も別途確認する。例: `70%` の行を `保留` にして `70%` が残ること。 |

### TC-07 進捗率列の直接変更

| 項目 | 内容 |
|---|---|
| 目的 | 進捗率を直接入力したときに、状況が正しく追従することを確認する |
| 手順 | 1. タスク行を 6 行用意する。<br>2. I列へ `0`、`0%`、`0.7`、`70`、`70%`、`100%` を入力する。<br>3. H列と I列の表示を確認する。 |
| 期待結果 | `0` と `0%` は `未着手 / 0%`。`0.7`、`70`、`70%` は `進行中 / 70%`。`100%` は `完了 / 100%`。 |
| 補足 | 複数セル貼り付けでも同じ結果になることを確認する。 |

### TC-08 不正な進捗率入力後の復旧

| 項目 | 内容 |
|---|---|
| 目的 | 不正入力後にイベント状態が壊れず、次の入力が通常通り反映されることを確認する |
| 手順 | 1. 通常モードで I列に `abc` など数値でない値を入力する。<br>2. エラーメッセージ確認後、同じ行または別行の I列に `70` を入力する。<br>3. H列と I列を確認する。<br>4. 自動テストでは `設定マスタ!B12` を TRUE にして、`-1` と数値でない値を入力する。 |
| 期待結果 | 通常モードでは不正値に警告が表示される。自動テストモードでは警告が表示されず、不正値が復旧し、`InvalidProgressInput` ログが残る。次の `70` 入力は `進行中 / 70%` になる。高速入力表示やボタン状態が勝手に変わらない。 |
| 補足 | Excel は `101%` を入力時点で数値へ変換するため、無人テストでは `-1` と数値でない値を不正値代表として確認する。 |

### TC-09 高速入力 ON 中に状況・進捗率を編集してから OFF

| 項目 | 内容 |
|---|---|
| 目的 | ON 中に H/I をまとめて変更しても、OFF 復帰時に仕様通り正規化されることを確認する |
| 手順 | 1. 高速入力を ON にする。<br>2. 複数行の H/I に `進行中`、`保留`、`70%`、`100%` などを貼り付ける。<br>3. 高速入力を OFF に戻す。 |
| 期待結果 | OFF 復帰後、状況と進捗率が仕様表通りに整合する。親集計やガント表示も更新される。 |
| 補足 | ON 中は即時反映されないため、判定は OFF 復帰後に行う。 |

### TC-10 ダブルクリック完了と高速入力の関係

| 項目 | 内容 |
|---|---|
| 目的 | B列または状況列のダブルクリック完了が、高速入力状態と矛盾しないことを確認する |
| 手順 | 1. 通常モードで未完了タスクの B列をダブルクリックする。<br>2. 別の未完了タスクを用意し、高速入力を ON にしてから B列をダブルクリックする。<br>3. 高速入力を OFF に戻す。 |
| 期待結果 | 通常モードでは `完了 / 100%` になる。高速入力 ON 中はダブルクリック完了が実行されず、ON 状態が壊れない。OFF 復帰後もエラーが出ない。 |
| 補足 | 状況列のダブルクリックでも同様に確認する。 |

### TC-11 ガント更新ボタン後の図形ずれ

| 項目 | 内容 |
|---|---|
| 目的 | `ガント更新` 実行後に、予定バー・進捗バー・実績線・今日線がずれないことを確認する |

| 期待結果 | 予定バーが L/M の日付範囲に合う。進捗バーが予定バー内に収まる。標準版の実績線が N/O に合う。今日線が今日の日付列にある。 |
| 補足 | 図形が日付列より 1 列以上ずれる、行から外れる、重複して濃くなる場合は NG。 |

## NG 時に残す情報

1. 対象ブックのパスとファイル名。
2. 実施した TC 番号。
3. 直前に押したボタン名。
4. 高速入力表示が ON か OFF か。
5. H/I の入力値と実際の表示値。
6. 図形ずれの場合は、日付ヘッダー、対象行、ずれた図形が同時に見えるスクリーンショット。
7. VBA エラーが出た場合は、エラーメッセージ全文。
