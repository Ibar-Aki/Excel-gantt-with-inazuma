# 高速入力と状況・進捗率の仕様レポート

- 作成日: 2026-05-05 18:53 JST
- 作成者: Codex (GPT-5)
- 更新日: 2026-05-07

## 対象

対象ブックは標準版 `InazumaGantt_v3` と簡易版 `InazumaGantt_Lite` です。対象列は `H:状況`、`I:進捗率`、対象操作は `一括編集 ON/OFF` の高速入力モードです。

## 調査結果

1. 進捗率の検証処理が、`Worksheet_Change` の内部で止めていた `Application.EnableEvents` を常に `True` に戻していました。
2. 高速入力 ON 中は `Application.EnableEvents=False` で自動更新を止める設計のため、進捗率変更後にイベント状態が想定外に戻ると、ON/OFF 表示と実状態がずれる可能性がありました。
3. 状況を `進行中` や `保留` に直接変更しても、既存ロジックが進捗率から状況を再推定し、ユーザーが選んだ状況が残らないケースがありました。

## 修正内容

1. `ValidateProgressInput` は呼び出し前の `Application.EnableEvents` を保存し、処理後に同じ状態へ戻すようにしました。
2. `ToggleBulkEditMode` は切替開始時にイベントを止めてから設定値、ボタン表示、インジケーターを更新し、OFF 復帰時だけイベントを `True` に戻すようにしました。
3. 状況を直接変更した場合は、選択された状況を優先して進捗率を補正する仕様に変更しました。
4. ビルド時スモークテストに、高速入力 ON/OFF、進捗率変更、状況変更、イベント復旧の確認を追加しました。
5. 設定マスタに `自動テストモード` を追加しました。通常利用では `FALSE` のまま使い、自動テスト中だけ確認メッセージをログ化します。
6. `CheckInazumaRuntimeState` を追加し、高速入力状態、イベント状態、ボタン重複、A3 インジケータをまとめて確認できるようにしました。
7. ガント更新時に、対象行範囲、更新図形数、削除図形数を隠しログシート `_InazumaGantt_Log` に記録するようにしました。
8. 進捗率の入力規則を、`0.7` / `70` / `70%` を受け付けやすい数値範囲チェックへ変更しました。
9. 状況・進捗率セルを選択したときに出る入力メッセージは表示しない仕様へ変更しました。
10. 高速入力 ON 中でも、空き行の C-F 列へ TASK を入力した場合は A 列の LV だけ即時表示するようにしました。
11. WBSサマリは、予定が片側の半月だけにある月では予定なし半月を白い `□` で表示し、予定が全くない月は空欄のままにしました。

## 高速入力 ON/OFF 仕様

| 状態 | 仕様 |
|---|---|
| ON | Excel 標準の `Ctrl+Z` を優先するため、`Worksheet_Change` による自動更新を停止します。 |
| ON 中 | 空き行の TASK 入力では LV だけ即時表示します。No.、親集計、アラート、色分け、ガント再描画は即時更新しません。必要なら `ガント更新` を手動実行します。 |
| OFF | 入力済みデータをまとめて再整合し、`Application.EnableEvents=True` に戻します。 |
| 状態ずれ検知時 | 主要マクロ入口やシート変更時に通常モードへ自動修復します。 |

## 状況・進捗率仕様

| 操作 | 結果 |
|---|---|
| 進捗率を空欄にする | `0%` として扱い、状況は `未着手` になります。 |
| 進捗率に `0` / `0%` を入力 | 進捗率は `0%`、状況は `未着手` になります。 |
| 進捗率に `0.7` / `70` / `70%` を入力 | 進捗率は `70%`、状況は `進行中` になります。 |
| 進捗率に `1` / `100` / `100%` を入力 | 進捗率は `100%`、状況は `完了` になります。 |
| 状況を `未着手` に変更 | 進捗率は `0%` になります。 |
| 状況を `進行中` に変更 | 進捗率が未入力、`0%`、`100%` の場合は `50%` に補正します。途中進捗が既にある場合は保持します。 |
| 状況を `完了` に変更 | 進捗率は `100%` になります。 |
| 状況を `保留` に変更 | 既存の進捗率を保持します。未入力の場合は `0%` になります。 |

状況列と進捗率列は、セル選択時の入力メッセージを表示しません。入力値が不正な場合の警告や復旧処理は従来どおり動作します。

## 自動テストモード仕様

| 項目 | 仕様 |
|---|---|
| 設定場所 | `設定マスタ!B12` |
| 通常値 | `FALSE` |
| TRUE の用途 | Excel COM などの無人テスト中に、確認メッセージで停止しないようにするためだけに使います。 |
| 土日祝日の予定日確認 | 通常時は確認メッセージを表示します。自動テストモードでは入力を許可し、ログに記録します。 |
| 不正な進捗率 | 通常時は警告を表示します。自動テストモードでは警告を出さず、値を復旧してログに記録します。 |

## 状態チェック・ログ仕様

| 項目 | 仕様 |
|---|---|
| 状態チェック | `CheckInazumaRuntimeState` で `OK` または `NG; ...` を返します。 |
| 確認対象 | メインシート、設定マスタ、高速入力設定、`Application.EnableEvents`、`Btn_BulkEdit` の重複、A3 インジケータです。 |
| ログシート | `_InazumaGantt_Log` に記録します。通常は非表示です。 |
| ガント更新ログ | `GanttRefresh` として、対象行範囲、更新図形数、削除図形数を記録します。 |
| 不正入力ログ | `InvalidProgressInput` として、不正値と対象セルを記録します。 |
