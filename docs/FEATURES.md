# 機能詳細

更新日: 2026-04-17

InazumaGantt v3 / Lite の現行仕様と主要マクロの一覧です。

## バージョン構成

| 版 | 特徴 |
|----|------|
| v3 | 実績列 `N:O` を持つ標準版 |
| Lite | 実績列なし。ガント開始列は `N`、単線表示 |

## 基本構成

| 列 | 項目 | 説明 |
|----|------|------|
| A | LV | タスク階層レベル |
| B | No. | 自動採番の通し番号 |
| C-F | TASK | LV1-LV4 のタスク入力列 |
| G | タスク詳細 | 補足説明 |
| H | 状況 | 未着手 / 進行中 / 完了 / 保留 |
| I | 進捗率 | 内部値は 0-1、表示は百分率 |
| J | 担当 | 担当者名 |
| K | 開発LT | 内部は数値保持、表示は `xh` 形式 |
| L | 開始予定 | 予定開始日 |
| M | 完了予定 | 予定完了日 |
| N | 開始実績 | 実績開始日 |
| O | 完了実績 | 実績完了日 |
| P以降 | ガント | 日次ガント領域 |

| 行 | 内容 |
|----|------|
| 6 | 週開始日 |
| 7 | 日付行 |
| 8 | 曜日とヘッダー |
| 9以降 | タスクデータ |

既定の入力対象行は No.1000 までです。

## ガント表示

| 要素 | 説明 |
|------|------|
| 予定バー | 開始予定から完了予定までを表示 |
| 進捗バー | 進捗率に応じて予定バー上に表示 |
| 実績バー | 開始実績から進捗位置までを表示 |
| 今日線 | 当日列に赤線を表示 |
| イナズマ線 | 各タスクの進捗位置をオレンジ線で接続 |
| 土日祝色分け | 土日と設定マスタの祝日を塗り分け |
| 完了行塗り分け | 完了時は LV と同じ範囲を薄い灰色で上書き表示 |
| C列アラート | LV2-LV4 に `!!` `!` の注意表示を出す |

## 自動入力と検証

| 機能 | 説明 |
|------|------|
| LV 自動判定 | C-F 列の入力位置から LV を設定 |
| No. 自動再採番 | 行挿入後も連番を振り直し |
| 状況 / 進捗同期 | `H` と `I` を相互同期し、空欄は `未着手 / 0%` に正規化 |
| 進捗率正規化 | `0.7` `70` `70%` を受け付ける |
| 開発LT正規化 | `3` `3h` `3.5h` を数値へ正規化し、表示は `xh` にそろえる |
| 日付検証 | 不正日付や前後逆転を警告 |
| 休日警告 | 予定日の土日祝入力時に確認メッセージを表示 |
| 親タスク自動再計算 | 変更行から祖先チェーンをたどって親タスクの状態、進捗率、LT、日付を更新 |
| LV2 fallback LT | 配下末端 LT が未入力の LV2 は、親行 K 列の手入力 LT を代表値として採用 |

## 操作支援

| 機能 | 説明 |
|------|------|
| ダブルクリック完了 | B列ダブルクリックで完了反映 |
| 折りたたみ | C-F 列で Shift + 右クリックすると LV1 配下を表示・非表示 |
| 開発LT集計 | K列で Shift + 右クリックすると配下末端タスク工数を集計 |
| 一括編集モード | 重い再計算を止めて行挿入 / 行削除 / 貼り付けをまとめて実施 |
| 土日切替 | 土日列の表示幅を切り替え |
| 日付シフト | 選択した日付を営業日単位で移動 |
| PDF出力 | 当月末までのガントを PDF 保存 |

## 俯瞰・補助シート

| シート | マクロ | 内容 |
|--------|--------|------|
| WBSサマリ | `CreateRoadmapOverviewSheet` | 月次に圧縮した全体計画と進捗を表示 |
| Showcase Sample | `CreateShowcaseSampleWBS` | 約150行の構造化サンプルWBSとロードマップを生成 |

## 主要マクロ一覧

| 区分 | マクロ名 | 用途 |
|------|----------|------|

| 書式 | `ToggleBulkEditMode` | 一括編集 ON / OFF |
| 書式 | `SetupHierarchyColors` | 階層色分けを再設定 |
| 補助 | `ToggleWeekends` | 土日列の表示切り替え |
| 補助 | `RenumberRows` | No. を再採番 |
| 補助 | `ShiftDates` | 日付一括シフト |
| 出力 | `ExportToPDF` | PDF出力 |
| 俯瞰 | `CreateRoadmapOverviewSheet` | WBSサマリ作成 |
| サンプル | `CreateShowcaseSampleWBS` | 大規模サンプルWBS作成 |
