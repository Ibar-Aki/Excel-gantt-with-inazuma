# 機能詳細

更新日: 2026-04-07

InazumaGantt v3 の主要機能と動作仕様です。

## 主要機能

### 1. イナズマガントチャート

| 要素 | 色 | 説明 |
|------|----|------|
| 予定バー | 薄い灰色 + 黒枠線 | 開始予定から完了予定まで |
| 進捗バー | 紺色 + 黒枠線 | 進捗率に応じて予定バー上に描画 |
| 実績バー | 緑色 | 開始実績から現在進捗位置まで |
| 今日線 | 赤 | 当日列の中央に縦線表示 |
| イナズマ線 | オレンジ | 各タスクの進捗位置を折れ線で連結 |
| 土日祝列 | 濃い灰色 | 土日と設定マスタの祝日を塗り分け |

#### イナズマ線の仕様

| 条件 | 結ぶ位置 |
|------|----------|
| 開始予定が今日より後 | 線に含めない |
| 完了済みかつ完了予定が今日以前 | 今日列の位置 |
| 完了済みかつ完了予定が今日より後 | 完了予定位置 |
| 進行中 | 進捗率に応じた位置 |
| 未着手 | 予定バー左端 |

### 2. 階層型タスク管理

| 入力列 | 階層 | 用途 | 色分け範囲 |
|--------|------|------|-----------|
| C列 | LV1 | 大項目・フェーズ | C〜N列 |
| D列 | LV2 | 中項目 | D〜N列 |
| E列 | LV3 | 小項目 | E〜N列 |
| F列 | LV4 | 詳細項目 | F〜N列 |

タスク入力時に LV と No. を自動補完します。

### 3. 自動入力・検証

| 機能 | 説明 |
|------|------|
| 進捗率初期値 | タスク入力時に `0` を設定 |
| 状況初期値 | タスク入力時に `未着手` を設定 |
| 状況自動更新 | 進捗率に応じて `未着手 / 進行中 / 完了` を更新 |
| 進捗率検証 | `0.7` `70` `70%` を受け付け、内部値を 0〜1 に正規化 |
| 日付検証 | 不正日付を拒否し、開始予定 > 完了予定 を警告 |
| 休日警告 | K-L 列に土日祝を入力したとき確認メッセージを表示 |

### 4. 操作支援

| 機能 | 説明 |
|------|------|
| ダブルクリック完了 | B列ダブルクリックで進捗率 100% と完了状態を設定 |
| 折りたたみ | Shift + 右クリックで LV1 配下を表示・非表示 |
| 土日切替 | 土日列の表示幅を切り替え |
| 日付シフト | 選択した日付セルを営業日単位で移動 |
| PDF出力 | 当月末までのガントを PDF として保存 |

## マクロ一覧

### 基本マクロ

| マクロ名 | 機能 |
|---------|------|
| `RunSetupWizard` | 初回セットアップ |
| `RefreshInazumaGantt` | ガント再描画 |
| `SetupHierarchyColors` | 階層色分けの設定 |
| `ResetFormatting` | ヘッダー、罫線、休日色の再構築 |

### 補助マクロ

| マクロ名 | 機能 |
|---------|------|
| `EnsureSettingsSheet` | 設定マスタの作成 |
| `ToggleWeekends` | 土日列の表示切り替え |
| `RenumberRows` | No. 列の再採番 |
| `ShiftDates` | 日付一括シフト |
| `ExportToPDF` | PDF 出力 |

## 列構成

| 列 | 項目 | 説明 |
|----|------|------|
| A | LV | 階層レベル |
| B | No. | 通し番号 |
| C-F | TASK | LV1-LV4 の入力列 |
| G | タスク詳細 | 補足説明 |
| H | 状況 | 未着手 / 進行中 / 完了 / 保留 |
| I | 進捗率 | 0〜1 で内部保持、表示は百分率 |
| J | 担当 | 担当者名 |
| K | 開始予定 | 予定開始日 |
| L | 完了予定 | 予定完了日 |
| M | 開始実績 | 実績開始日 |
| N | 完了実績 | 実績完了日 |
| O以降 | ガント | 120日分のガント領域 |

## 行構成

| 行 | 内容 |
|----|------|
| 6 | 週開始日 |
| 7 | 日付 |
| 8 | 曜日と A-N ヘッダー |
| 9以降 | タスクデータ |
