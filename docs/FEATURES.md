# 機能詳細

更新日: 2026-04-24

InazumaGantt v3 / Lite の現行仕様と主要マクロの一覧です。

## バージョン構成

| 版 | 特徴 |
|----|------|
| v3 | 実績列 `N:O` を持つ標準版 |
| Lite | 実績列なし。ガント開始列は `N`、単線表示 |

## 基本構成

| 列 | 項目 | 説明 |
|----|------|------|
| A | LV | タスク階層レベル |
| B | No. | 自動採番の通し番号 |
| C-F | TASK | LV1-LV4 のタスク入力列 |
| G | タスク詳細 | 補足説明 |
| H | 状況 | 未着手 / 進行中 / 完了 / 保留 |
| I | 進捗率 | 内部値は 0-1、表示は百分率 |
| J | 担当 | 担当者名 |
| K | 開発LT | 内部は数値保持、表示は `xh` 形式 |
| L | 開始予定 | 予定開始日 |
| M | 完了予定 | 予定完了日 |
| N | 開始実績 | 実績開始日 |
| O | 完了実績 | 実績完了日 |
| P以降 | ガント | 日次ガント領域 |

| 行 | 内容 |
|----|------|
| 6 | 週開始日 |
| 7 | 日付行 |
| 8 | 曜日とヘッダー |
| 9以降 | タスクデータ |

既定の入力対象行は No.1000 までです。

## ガント表示

| 要素 | 説明 |
|------|------|
| 予定バー | 開始予定から完了予定までを表示 |
| 進捗バー | 進捗率に応じて予定バー上に表示 |
| 実績バー | 開始実績から進捗位置までを表示 |
| 今日線 | 当日列に赤線を表示 |
| イナズマ線 | 各タスクの進捗位置をオレンジ線で接続 |
| 土日祝色分け | 土日と設定マスタの祝日を塗り分け |
| 完了行塗り分け | 完了時は LV と同じ範囲を薄い灰色で上書き表示 |
| C列アラート | LV2-LV4 に `!!` `!` の注意表示を出す |

## 自動入力と検証

| 機能 | 説明 |
|------|------|
| LV 自動判定 | C-F 列の入力位置から LV を設定 |
| No. 自動再採番 | 行挿入、貼り付け、タスク有無の変化では連番を振り直し。単一セルの文言編集では全体再採番を抑制 |
| 状況 / 進捗同期 | `H` と `I` を相互同期し、空欄は `未着手 / 0%` に正規化 |
| 進捗率正規化 | `0.7` `70` `70%` を受け付ける |
| 開発LT正規化 | `3` `3h` `3.5h` を数値へ正規化し、表示は `xh` にそろえる |
| 日付検証 | 不正日付や前後逆転を警告 |
| 休日警告 | 予定日の土日祝入力時に確認メッセージを表示 |
| 親タスク自動再計算 | 通常入力では変更行から祖先チェーンだけをたどり、親タスクの状態、進捗率、LT、日付、C列警告を更新 |
| LV2 fallback LT | 配下末端 LT が未入力の LV2 は、親行 K 列の手入力 LT を代表値として採用 |

## 操作支援

| 機能 | 説明 |
|------|------|
| ダブルクリック完了 | B列ダブルクリックで完了反映 |
| 折りたたみ | C-F 列で Shift + 右クリックすると LV1 配下を表示・非表示 |
| 開発LT集計 | K列で Shift + 右クリックすると配下末端タスク工数を集計 |
| 一括編集モード | Ctrl+Z を優先する高速入力モード。ON 中は自動再計算 / 再描画を止め、OFF で一括再整合。状態不整合は通常モードへ自動修復 |
| WBS退避 / 復元 | 見出し付き `A:O` の値・書式・入力規則を最新 1 枚のコピーシートへ退避し、確認後に本体へ戻せる。退避は一時シート差し替え、復元はロールバック付き |
| 土日切替 | 土日列の表示幅を切り替え |
| 日付シフト | 選択した日付を営業日単位で移動 |
| PDF出力 | 当月末までのガントを PDF 保存 |
| WBSサマリ表示階層 | 設定マスタ B11 で `LV1のみ` / `LV2まで` を切り替え |

## 俯瞰・補助シート

| シート | マクロ | 内容 |
|--------|--------|------|
| WBSサマリ | `CreateRoadmapOverviewSheet` | 月次に圧縮した全体計画と進捗を表示。`LV2まで` では LV2 行を折りたたみ可能な詳細行として追加 |
| Showcase Sample | `CreateShowcaseSampleWBS` | 約150行の構造化サンプルWBSとロードマップを生成 |

## 主要マクロ一覧

| 区分 | マクロ名 | 用途 |
|------|----------|------|
| 初期設定 | `RunSetupWizard` | 初回セットアップ |
| 再描画 | `RefreshInazumaGantt` | ガント、親集計、警告表示、ヘッダー、罫線、土日祝色をまとめて更新 |
| 互換 | `ResetFormatting` | 旧手順互換。内部では `RefreshInazumaGantt` を実行 |
| 書式 | `ToggleBulkEditMode` | Ctrl+Z 優先の高速入力 ON / OFF |
| 補助 | `CreateWbsBackupSheet` | 見出し付き `A:O` の値・書式・入力規則を一時シート経由で最新バックアップシートへ退避 |
| 補助 | `RestoreWbsFromBackupSheet` | 更新日時を確認してからバックアップシートの `A:O` をロールバック付きで復元し、通常モードへ戻す |
| 書式 | `SetupHierarchyColors` | 階層色分けを再設定 |
| 補助 | `ToggleWeekends` | 土日列の表示切り替え |
| 補助 | `RenumberRows` | No. を再採番 |
| 補助 | `ShiftDates` | 日付一括シフト |
| 出力 | `ExportToPDF` | PDF出力 |
| 俯瞰 | `CreateRoadmapOverviewSheet` | WBSサマリ作成 |
| サンプル | `CreateShowcaseSampleWBS` | 大規模サンプルWBS作成 |

## 安全性と配布時の挙動

- `CreateWbsBackupSheet` は既存バックアップを直接消さず、一時シートにコピーが完了してから `WBS_Backup_v3` / `WBS_Backup_Lite` へ差し替えます。
- `RestoreWbsFromBackupSheet` は本 WBS を一時退避してから復元するため、貼り付けや再整合に失敗した場合は復元前の `A:O` へロールバックします。
- ビルド時 smoke test はバックアップ作成・復元マクロも実行しますが、保存前に `WBS_Backup_*` と一時シートを削除するため、配布ブックにビルド時バックアップは含まれません。
- `Worksheet_Change` はアプリ状態を最初に退避し、エラー時も `EnableEvents` / `Calculation` / `ScreenUpdating` を取得済み状態へ戻します。
