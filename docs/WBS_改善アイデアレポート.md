## 目的

本レポートは、現行の Excel ベース WBS / イナズマガントをさらに使いやすくし、計画精度、運用効率、進捗可視化、保守性を高めるための改善アイデアを整理したものです。

## 総評

現状の WBS は、日単位の詳細管理、進捗入力、階層管理、ガント可視化という基本機能が揃っており、現場で実運用できる水準にあります。一方で、実務上の使いやすさをさらに高める余地は大きく、特に以下の 4 点に改善余地があります。

- 全体俯瞰はまだ弱く、経営層・PM 向けの短時間把握がしづらい
- 入力補助と異常検知が限定的で、運用ルールが人依存になりやすい
- 実績蓄積や振り返りの仕組みが弱く、計画精度改善につながりにくい
- シート数や運用者が増えたときの保守・統制機能がまだ少ない

## 優先度の高い改善案

### 1. ダッシュボードシート

- 内容: 全体進捗、遅延フェーズ数、今週完了予定件数、未着手件数、担当別負荷を 1 画面に集約
- 効果: 朝会や定例での確認時間を大きく短縮できる
- 実装イメージ: KPI カード + 進捗円グラフ + 遅延一覧 + 担当別件数表
- 状態: 実装済み
- 優先度: 高

### 2. 遅延・期限接近アラート

- 内容: 「期限超過」「3営業日以内に期限」「開始予定未着手」などを自動抽出する別シートや強調表示を追加
- 効果: 問題の早期発見がしやすくなる
- 実装イメージ: `遅延一覧` シート生成マクロ、または条件付き書式で赤・黄警告
- 優先度: 高

### 3. 担当者別負荷表

- 内容: 担当者ごとの総開発LT、残開発LT、進行中件数、今週期限件数を集計
- 効果: アサイン偏りの是正、マネジメント判断がしやすくなる
- 実装イメージ: `担当別負荷` シートを生成し、工数順・残工数順で並べ替え
- 優先度: 高

### 4. クリティカルタスク抽出

- 内容: 遅延している親フェーズに属するタスク、または全体進捗に影響の大きい高工数タスクを抽出
- 効果: 重要タスクの見落としを防げる
- 実装イメージ: 高 LT、期限近、進捗低の複合条件でスコアリング
- 優先度: 高

### 5. 入力支援メニュー

- 内容: 行追加、子タスク追加、親タスク追加、テンプレート複製をボタン化
- 効果: 操作の学習コストを下げられる
- 実装イメージ: 「選択行の下に LV3 を追加」「選択行の子として LV4 を追加」など
- 優先度: 高

## 運用を楽にする改善案

### 6. フィルタビュー用シート

- 内容: 「未完了のみ」「自分担当のみ」「今週期限のみ」「遅延のみ」をワンクリック表示
- 効果: 元データを壊さず、目的別に見やすくなる
- 実装イメージ: 一時抽出シート生成、または保存済みビューの再適用
- 状態: 実装済み

### 7. 週次レビュー用出力

- 内容: 先週完了、今週予定、遅延、リスク項目を 1 シートへ自動整理
- 効果: 週次会議資料の作成が楽になる
- 実装イメージ: `週次レビュー` シート生成マクロ

### 8. 会議用印刷レイアウト

- 内容: A4 横・月単位・主要列のみの印刷用シートを自動生成
- 効果: Excel を触らない関係者にも共有しやすい
- 実装イメージ: `会議用ロードマップ` シート生成 + PDF 出力

### 9. タスクテンプレート

- 内容: よく使う WBS 雛形を設定マスタまたは別シートに持ち、案件種別ごとに投入
- 効果: 新規案件立ち上げが速くなる
- 実装イメージ: 「開発案件」「保守案件」「リリース案件」テンプレート挿入

### 10. 進捗更新漏れチェック

- 内容: 一定期間更新がない進行中タスクを一覧化
- 効果: 実態と台帳の乖離を減らせる
- 実装イメージ: 最終更新日時列を追加して監視

## 計画精度を上げる改善案

### 11. 実績 LT 蓄積

- 内容: 開発LTとは別に実績工数列を持ち、完了時に差異分析できるようにする
- 効果: 見積精度の改善につながる
- 実装イメージ: `見積LT`, `実績LT`, `差異` を追加

### 12. 工数消化予測

- 内容: 現在進捗から完了予測日と残工数を推定
- 効果: 遅延予兆が早く見える
- 実装イメージ: 進捗率、残 LT、営業日換算から簡易予測

### 13. ベースライン比較

- 内容: 当初計画と現時点計画の差分を比較
- 効果: スコープ増加や計画変更の影響を説明しやすい
- 実装イメージ: ベースライン日付列、差分日数列、差分色付け

### 14. リスク登録欄

- 内容: タスクまたはフェーズ単位でリスク、対策、オーナー、期限を持てるようにする
- 効果: WBS とリスク管理の分断を減らせる
- 実装イメージ: `リスク`, `対策`, `対応者` 列または別シート

## UX / 操作性の改善案

### 15. 右クリックメニュー拡張

- 内容: 折りたたみや開発LT集計だけでなく、子タスク追加、担当コピー、日付シフト、行移動を実行
- 効果: マクロ名を覚えなくてよくなる
- 実装イメージ: ショートカットメニューへの追加

### 16. 色の意味の明確化

- 内容: 判定、進捗、遅延、保留の配色を統一し、凡例を常設
- 効果: 初見でも理解しやすい
- 実装イメージ: 固定凡例欄、ステータス色の標準化

### 17. 行の視認性改善

- 内容: 親子階層のインデント、折りたたみ状態アイコン、交互背景を強化
- 効果: 大規模 WBS でも追いやすい
- 実装イメージ: LV ごとの字下げ、記号、行バンド

### 18. 検索・ジャンプ機能

- 内容: タスク名検索、担当者検索、No.ジャンプ
- 効果: 大きい WBS の探索コストを下げられる
- 実装イメージ: 入力ボックスまたは検索シート

## データ品質・統制の改善案

### 19. 必須入力チェック

- 内容: フェーズ完了前に担当、予定日、進捗率などの必須項目を検証
- 効果: 不完全データのまま運用されるのを防げる
- 実装イメージ: `ValidateWBSIntegrity` マクロ

### 20. 不整合チェックシート

- 内容: 開始 > 完了、100% なのに完了日なし、未着手なのに実績日あり等を一覧化
- 効果: 品質監査がしやすい
- 実装イメージ: `WBS整合性チェック` シート生成

### 21. 変更履歴

- 内容: 重要項目の更新ログを別シートに記録
- 効果: いつ誰が何を変えたか追いやすい
- 実装イメージ: シートイベントで差分を履歴追記

### 22. ロックと編集権限の分離

- 内容: 編集してよい列だけを解放し、式や集計シートは保護
- 効果: 誤操作耐性が上がる
- 実装イメージ: シート保護、入力セルのみ編集可

## 連携・拡張の改善案

### 23. CSV / TSV 入出力

- 内容: 外部台帳や他ツールと相互連携できるようにする
- 効果: Excel 外との橋渡しになる
- 実装イメージ: インポート / エクスポート専用マクロ

### 24. チケット連携用列

- 内容: Backlog / Jira / GitHub Issue などの URL や ID を持てるようにする
- 効果: 実作業と管理台帳をつなげやすい
- 実装イメージ: `チケットID`, `URL` 列追加

### 25. 実績スナップショット保存

- 内容: 日次または週次で進捗状態を別シートへスナップショット保存
- 効果: 振り返りや差分説明に使える
- 実装イメージ: `履歴_YYYYMMDD` シート生成

## 保守性・技術的改善案

### 26. レポート系マクロのモジュール分離

- 内容: 本体ガント描画と、サマリ・ロードマップ・監査系を別モジュールへ分離
- 効果: 今後の機能追加が楽になる
- 実装イメージ: `InazumaGanttReports.bas` 新設

### 27. 列定義の設定化

- 内容: 表示列の ON/OFF や列順カスタマイズを設定マスタで制御
- 効果: 現場ごとの運用差に対応しやすい
- 実装イメージ: 設定マスタに表示フラグを追加

### 28. 機能別テストマクロ

- 内容: 整合性チェック、ロードマップ生成、No.再採番などを検証するスモーク群を用意
- 効果: 修正時の回帰を減らせる
- 実装イメージ: `dev/extra_modules` 相当のテスト整備
