# 進捗管理表 利用マニュアル (v3 / Lite)

更新日: 2026-04-23

## バージョン選択

| 版 | 向いているケース |
|---|---|
| v3 | 実績開始日 / 実績完了日まで管理したい |
| Lite | 計画と進捗だけを軽く管理したい |

## 表の見方

| 列 | 項目名 | 入力内容 |
|---|---|---|
| A | LV | 自動入力 |
| B | No. | 自動採番 |
| C-F | TASK | 階層に応じたタスク名。LV2-LV4 は C列に注意マーク表示あり |
| G | タスク詳細 | 補足情報 |
| H | 状況 | 未着手 / 進行中 / 完了 / 保留 |
| I | 進捗率 | `70%` `70` `0.7` のいずれでも入力可 |
| J | 担当 | 担当者名 |
| K | 開発LT | `3` `3h` `5.5h` のいずれでも入力可。内部は数値保持 |
| L | 開始予定 | 開始予定日 |
| M | 完了予定 | 完了予定日 |
| N | 開始実績 | 実際の開始日 |
| O | 完了実績 | 実際の完了日 |

## タスクの入力方法

| 階層 | 入力列 | 例 |
|---|---|---|
| LV1 | C列 | 計画フェーズ |
| LV2 | D列 | 要件定義 |
| LV3 | E列 | ヒアリング |
| LV4 | F列 | 詳細確認 |

入力した列に応じて LV と No. が自動設定されます。既定の入力範囲は No.1000 までです。

## 日付と進捗の入力

1. L-M 列に開始予定と完了予定を入力します。
2. 作業開始時に N 列へ開始実績を入力します。
3. 作業中は I 列の進捗率を更新します。
4. 完了時は O 列へ完了実績を入れるか、B 列ダブルクリックで完了にします。

`H:状況` と `I:進捗率` は自動で同期されます。`H` が空欄なら `未着手`、`I` が空欄なら `0%` になります。`完了` は `100%`、`未着手` は `0%` にそろいます。

## よく使う操作

| 操作 | 内容 |
|---|---|
| B列ダブルクリック | 進捗率 100% と完了状態を反映 |
| C-F列で Shift + 右クリック | LV1 配下の折りたたみ / 展開 |
| K列で Shift + 右クリック | 配下末端タスクの開発LTを親行へ集計 |
| ガント更新 | 日付、進捗、親集計、警告表示、基本書式をまとめて更新 |
| 土日切替 | 土日列の表示 / 非表示 |
| 一括編集 ON/OFF | Ctrl+Z を優先する高速入力モード。ON 中は自動更新を止め、OFF で一括再整合 |
| WBS退避 | 見出し付き `A:O` の値・書式・入力規則を最新バックアップシートへコピー |
| バックアップ復元 | 更新日時を確認してから最新バックアップを本 WBS へ戻し、通常モードで再整合 |

完了行は、各 LV の塗り範囲に合わせて薄い灰色で表示されます。

## 親タスク自動再計算

1. 子タスクの `H:状況` `I:進捗率` `K:開発LT` `L:O` を更新すると、変更行と祖先チェーンだけが自動で再計算されます。
2. 進捗率は開発LTの重み付き平均で計算されます。
3. 親タスクの状態は、遅延、完了、進行中、予定前、未着手の順で自動判定されます。
4. LV2 配下に末端タスク LT が無い場合だけ、LV2 の K 列手入力値を代表 LT として扱います。

## 一括編集モード

1. 大量の行挿入、行削除、貼り付け、ドラッグ移動の前に `一括編集 ON` にします。
2. ON にすると `Worksheet_Change` ベースの自動更新を止めるため、Excel 標準の `Ctrl+Z` を使いやすくなります。
3. ON 中は LV、No.、親再計算、C 列アラート、階層色分け、ガント再描画を自動では更新しません。
4. 必要なら ON 中でも `ガント更新` を押して、現時点の表示だけを手動で反映できます。
5. 作業が終わったら `一括編集 OFF` に戻します。
6. OFF に戻したタイミングで、LV、No.、親タスク、アラート、色分け、ガントがまとめて再整合されます。

## WBSバックアップ

1. `WBS退避` を押すと、見出し付き `A:O` 範囲の値・書式・入力規則が `WBS_Backup_v3` / `WBS_Backup_Lite` シートへ保存されます。
2. バックアップは最新 1 枚固定です。押し直すと同じシートが更新されます。
3. バックアップシート右上には更新日時と元シート名が記録されます。
4. ガント領域やボタンはバックアップ対象外です。復元後に再描画で戻ります。
5. `バックアップ復元` を押すと、確認ダイアログで更新日時を確認したうえで、バックアップの `A:O` を本シートへ戻し、通常モードで全体再整合します。
6. 復元後は高速入力 OFF に戻ります。

## C列の注意マーク

1. LV1 には注意マークは表示しません。
2. `!!` は期限超過の業務です。
3. `!` は今日着手または今日完了予定の業務です。
4. 今週着手予定だけでは、C列に追加の記号や塗りつぶしは出しません。

## 俯瞰シートの使い分け

| シート | 使いどころ |
|---|---|
| WBSサマリ | 月次で全体計画を俯瞰したいとき |

`設定マスタ` の `WBSサマリ表示階層` を `LV2まで` にすると、WBSサマリに LV2 の詳細行も追加されます。LV2 行は初期状態では折りたたまれ、左端のアウトラインから展開できます。合計や全体進捗は LV1 行だけを対象にするため、LV2 行を表示しても二重計上されません。

## よく使うマクロ

| マクロ | 内容 |
|---|---|
| `RunSetupWizard` | 初回セットアップ |
| `RefreshInazumaGantt` | ガント、親集計、警告表示、ヘッダー、罫線、土日祝色をまとめて更新 |
| `ToggleBulkEditMode` | Ctrl+Z 優先の高速入力 ON / OFF |
| `CreateWbsBackupSheet` | 見出し付き `A:O` の値・書式・入力規則を最新バックアップシートへ退避 |
| `RestoreWbsFromBackupSheet` | 更新日時を確認してからバックアップシートの `A:O` を復元し、通常モードで再整合 |
| `ExportToPDF` | 当月末までの PDF 出力 |
| `CreateRoadmapOverviewSheet` | WBSサマリ作成 |
| `CreateShowcaseSampleWBS` | 約150行のサンプルWBSを投入し、ロードマップも作成 |

## サンプルWBSの見どころ

1. テーマは「会話力向上アプリ『ハナセル』」です。
2. 完了タスクは、LV の塗り範囲と同じ幅で薄い灰色に統一表示されます。
3. サンプル投入時に `WBSサマリ` も同時生成されます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| ガントが更新されない | `RefreshInazumaGantt` を実行 |
| 行挿入後に No. がずれた | タスク入力後に自動再採番されるか確認し、必要なら `RenumberRows` を実行 |
| 高速入力 OFF 後に表示が合わない | `RefreshInazumaGantt` を 1 回実行し、必要なら `バックアップ復元` を使う |
| 休日色がおかしい | `RefreshInazumaGantt` を実行 |
| 全体計画が見づらい | `CreateRoadmapOverviewSheet` を実行 |
