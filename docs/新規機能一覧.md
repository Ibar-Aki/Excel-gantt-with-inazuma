# 新規機能一覧

作成日: 2026-04-10 00:47 JST
作成者: Codex (GPT-5)
更新日: 2026-04-11

直近で追加した主要機能を、用途と実行マクロ単位で整理した一覧です。

## 対象バージョン

- 3.0.1
- 3.1.0
- 3.1.1
- 3.1.2

## 一覧

| バージョン | 機能 | マクロ | モジュール | 概要 |
|-----------|------|--------|------------|------|
| 3.0.1 | 開発LT列 | なし | `InazumaGantt_v3` | K列に `xh` 形式の工数入力列を追加 |
| 3.0.1 | 工数ロールアップ | Shift + 右クリック | `SheetModule` / `InazumaGantt_v3` | 親行で配下末端タスクの開発LTを集計 |
| 3.0.1 | 日付列再配置 | なし | `InazumaGantt_v3` | 予定・実績列を L-O、ガント開始列を P に変更 |
| 3.1.0 | 入力範囲拡張 | なし | `InazumaGantt_v3` | 書式とマクロ対象の既定範囲を No.1000 まで拡張 |
| 3.1.0 | WBS全体サマリ | `CreatePhaseSummarySheet` | `WBSOverviewReports` | フェーズ単位の進捗、工数、遅延を集計 |
| 3.1.0 | WBSロードマップ | `CreateRoadmapOverviewSheet` | `WBSOverviewReports` | 月次に圧縮した全体計画と進捗を表示 |
| 3.1.1 | WBSダッシュボード | `CreateWBSDashboardSheet` | `WBSDashboardViews` | KPI、担当負荷、要注意タスクを一覧化 |
| 3.1.1 | WBSフィルタビュー | `CreateWBSFilterViewSheet` | `WBSDashboardViews` | 担当、状態、期限観点で絞り込みやすい一覧を生成 |
| 3.1.2 | Showcase Sample | `CreateShowcaseSampleWBS` | `WBSSampleShowcase` | 約150行の見栄え重視サンプルWBSを生成 |

## 使い分け

| 見たい内容 | 推奨機能 |
|-----------|----------|
| フェーズ単位の進捗と遅延 | `CreatePhaseSummarySheet` |
| 月次で見た全体計画 | `CreateRoadmapOverviewSheet` |
| 朝会向けの要点整理 | `CreateWBSDashboardSheet` |
| 担当別、状態別の絞り込み確認 | `CreateWBSFilterViewSheet` |

## 補足

- 俯瞰系マクロはメインシート `InazumaGantt_v3` を元データとして別シートを再生成します。
- Excel へ取り込むファイルは `_SJIS.bas` です。
- `SheetModule_SJIS.bas` は標準モジュールではなく、`InazumaGantt_v3` シートモジュールへ貼り付けます。
