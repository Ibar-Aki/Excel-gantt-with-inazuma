タスクの入力方法

階層 入力列 例
LV1 C列 計画フェーズ
LV2 D列 要件定義
LV3 E列 ヒアリング
LV4 F列 詳細確認

入力した列に応じて LV と No. が自動設定されます。既定の入力範囲は No.1000 までです。

日付と進捗の入力

  1. L-M 列に開始予定と完了予定を入力します。
  2. 作業開始時に N 列へ開始実績を入力します。
  3. 作業中は I 列の進捗率を更新します。
  4. 完了時は O 列へ完了実績を入れるか、B 列ダブルクリックで完了にします。

H:状況 と I:進捗率 は自動で同期されます。進捗率を入力した場合は、0% が 未着手、1% から 99% が 進行中、100% が 完了 になります。状況を直接選んだ場合は、完了 が 100%、未着手 が 0%、進行中 が未入力または端数値のとき 50% にそろいます。保留 は入力済みの進捗率を保持し、未入力なら 0% になります。

親タスク自動再計算

  1. 子タスクの H:状況 I:進捗率 K:開発LT L:O を更新すると、変更行と祖先チェーンだけが自動で再計算されます。
  2. 進捗率は開発LTの重み付き平均で計算されます。
  3. 親タスクの状態は、遅延、完了、進行中、予定前、未着手の順で自動判定されます。
  4. LV2 配下に末端タスク LT が無い場合だけ、LV2 の K 列手入力値を代表 LT として扱います。
  5. 親タスクの L:開始予定 と M:完了予定 が空欄の場合、ガント更新 で配下タスクの最小開始日と最大完了日が入ります。
  6. 親タスクの L:M を手で直した場合、そのセルは手入力値として保持されます。開始予定と完了予定は別々に判定されます。
  7. 手入力した親タスク日付を空欄に戻すと、次回の ガント更新 で自動計算へ戻ります。
  8. 親予定日の自動値と手入力判定は非表示シート _InazumaParentDateState に保持されます。通常操作で編集する必要はありません。

一括編集モード

  1. 大量の行挿入、行削除、貼り付け、ドラッグ移動の前に 一括編集 ON にします。
  2. ON にすると Worksheet_Change ベースの自動更新を止めるため、Excel 標準の Ctrl+Z を使いやすくなります。
  3. ON 中でも、空き行の C-F 列にタスク名を入力した場合は A 列の LV だけ即時表示されます。
  4. ON 中は No.、親再計算、C 列アラート、階層色分け、ガント再描画は自動では更新しません。
  5. 必要なら ON 中でも ガント更新 を押して、現時点の表示だけを手動で反映できます。
  6. 作業が終わったら 一括編集 OFF に戻します。
  7. OFF に戻したタイミングで、LV、No.、親タスク、アラート、色分け、ガントがまとめて再整合されます。
  8. Excel 再起動や VBA リセットで 設定マスタ の高速入力表示と実際のイベント状態がずれた場合は、シート変更時または主要マクロ実行時に通常モードへ自動修復します。
  9. 高速入力の ON/OFF と状況・進捗率の詳しい仕様は docs/高速入力_状況_進捗率仕様レポート.md を参照してください。

設定マスタの保守項目

通常利用では、設定マスタ の 自動テストモード は FALSE のまま使います。これは Excel COM などの無人テスト時に確認メッセージをログ化するための保守用設定です。

CheckInazumaRuntimeState を実行すると、高速入力状態、イベント状態、ボタン重複、A3 インジケータの整合をまとめて確認できます。ガント更新や不正入力の保守ログは、非表示シート _InazumaGantt_Log に記録されます。

WBSバックアップ

  1. WBS退避 を押すと、見出し付き A:O 範囲の値・書式・入力規則が WBS_Backup_v3 / WBS_Backup_Lite シートへ保存されます。
  2. バックアップは最新 1 枚固定です。押し直すと一時シートに完全コピーしてから既存バックアップと差し替えます。
  3. バックアップシート右上には更新日時と元シート名が記録されます。
  4. ガント領域やボタンはバックアップ対象外です。復元後に再描画で戻ります。
  5. バックアップ復元 を押すと、確認ダイアログで更新日時を確認したうえで、バックアップの A:O を本シートへ戻し、通常モードで全体再整合します。
  6. 復元中は直前の本 WBS を一時退避します。貼り付けや再整合で失敗した場合は、できる限り復元前の状態へロールバックします。
  7. 復元後は高速入力 OFF に戻ります。
  8. 配布ブックにはビルド時 smoke test で作成した WBS_Backup_* シートを残しません。利用者が WBS退避 を押すまでバックアップシートは作成されません。

C列の注意マーク

  1. !! は未完了のまま完了予定日を過ぎている業務です。
  2. ! は開始予定から完了予定までの期間が今週と重なる未完了業務です。
  3. 下位タスクに !! または ! が付いた場合、上位タスクにも同じ注意マークが付きます。
  4. !! と ! が同じ配下に混在する場合は、より強い !! が上位タスクへ表示されます。
  5. LV1 のように C 列へタスク名が入っている行は、!! タスク名 のようにタスク名の前へ表示されます。LV2-LV4 のように D-F 列へタスク名がある行は、C 列に !! または ! だけが表示されます。
  6. 予定日は通常の日付入力だけでなく、Excel シリアル値として入った日付も判定対象です。

俯瞰シートの使い分け

シート 使いどころ
WBSサマリ 月次で全体計画を俯瞰したいとき

設定マスタ の WBSサマリ表示階層 を LV2まで にすると、WBSサマリに LV2 の詳細行も追加されます。LV2 行は初期状態では折りたたまれ、左端のアウトラインから展開できます。合計や全体進捗は LV1 行だけを対象にするため、LV2 行を表示しても二重計上されません。

WBSサマリの月次表示は、月を前半・後半の 2 枠で表します。片側だけ予定がある月では、予定がない半月を白い □ で表示します。予定が全くない月は空欄のままです。

親予定日の詳しい仕様は docs/親タスク予定日_仕様レポート.md を参照してください。

サンプルWBSの見どころ

  1. テーマは「会話力向上アプリ『ハナセル』」です。
  2. 完了タスクは、LV の塗り範囲と同じ幅で薄い灰色に統一表示されます。
  3. サンプル投入時に WBSサマリ も同時生成されます。
